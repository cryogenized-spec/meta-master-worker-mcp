# M1 — Secure MCP resource transport

**State: implementation in progress.** The M0 Worker shell remains fail-closed unless an independent authorization service is configured. This increment does not link Meta accounts or deploy services.

## Resource-server implementation

- Official SDK v2 stateless Streamable HTTP handler with one non-sensitive tool, `meta_connection_status`.
- Cloudflare Workers OAuth Provider v1 resource-server gate.
- Protected-resource audience bound to the exact configured MCP URI.
- `mcp:read` checked inside authenticated handler (not merely advertised).
- Config validator refuses missing service bindings, malformed URLs and non-loopback HTTP endpoints.
- Unconfigured `/mcp` responds with 503; OAuth metadata is absent until bindings exist.
- SDK imports are lazy-loaded only after configuration to keep tests fail-closed without infrastructure.

## Future Cloudflare bindings — not provisioned

`MCP_SERVER_URL`: canonical absolute HTTPS URL ending in `/mcp`.

`AUTH_SERVER_URL`: canonical URL of separate OAuth issuer.

`AUTH_SERVER`: Cloudflare Service Binding to auth Worker with token-validation entrypoint.

Loopback HTTP is permitted for local testing only. Do not commit credentials or deploy this pre-auth build.
